# Laser Filamentation: Nonlinear Self-Channeling of Light

Classical Electrodynamics project by second-year Bachelor students at École Polytechnique.

This project studies laser filamentation and nonlinear self-channeling of light, with a focus on cylindrically symmetric ultrashort pulse propagation. It combines the physical mechanisms behind filament formation — Kerr self-focusing, diffraction, group-velocity dispersion, multiphoton absorption, plasma generation and plasma defocusing — with numerical simulations of the electric-field envelope.

The repository contains the final report and the Jupyter notebook used to generate and analyse the simulation results.
